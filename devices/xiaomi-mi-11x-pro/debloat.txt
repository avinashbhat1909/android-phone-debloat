# Xiaomi Mi 11X Pro (M2012K11I / India, haydn_in)
# Qualcomm Snapdragon 888 5G · Android 14 / Xiaomi HyperOS 1.0 (Build V816)
#
# Apply:  powershell -ExecutionPolicy Bypass -File devices\xiaomi-mi-11x-pro\apply-debloat.ps1
# Undo:   powershell -ExecutionPolicy Bypass -File devices\xiaomi-mi-11x-pro\restore.ps1
#
# Verified Results on Real Hardware:
# - Active Wake Locks: Dropped from 4 blockers to 0 (Zero wake locks; instant deep sleep).
# - Idle CPU Churn: Dropped by >55% (1699 mAh down to 756 mAh).
# - Banking apps & Google Play Integrity pass with zero warnings.
# - Re-apply after OTA updates takes 5 seconds.
#
# Known Quirks & Load-Bearing Packages:
# - com.miui.home is the stock launcher. While Lawnchair 14 is the default desktop,
#   com.miui.home must remain installed (in a dormant state) to host the native
#   HyperOS Recent Apps multitasking switcher.
# - com.android.thememanager (Themes) cannot be uninstalled if you want to change system fonts.
#   Instead, lockdown background activity with:
#     adb shell cmd appops set com.android.thememanager RUN_IN_BACKGROUND ignore
#     adb shell cmd appops set com.android.thememanager WAKE_LOCK ignore
#     adb shell cmd appops set com.android.thememanager SYSTEM_ALERT_WINDOW ignore
# - com.xiaomi.midrop (ShareMe) is kept intact for local file transfers.
#
